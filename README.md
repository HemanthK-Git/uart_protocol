# UART Protocol - SystemVerilog Implementation

A UART (Universal Asynchronous Receiver-Transmitter) protocol implementation in SystemVerilog.

## Project Overview

This project implements a UART communication protocol in SystemVerilog, designed for FPGA/ASIC development.

## Project Structure

```
uart_protocol/
├── uart.sv           # UART module implementation
├── uart_tb.sv        # UART testbench
├── uart_protocol.xpr # Vivado project file
└── README.md         # This file
```

## Features

- [ ] UART transmitter
- [ ] UART receiver
- [ ] Configurable baud rate
- [ ] Parity checking
- [ ] Full testbench coverage

## Getting Started

### Prerequisites

- Vivado Design Suite (for simulation and synthesis)
- SystemVerilog compatible simulator (ModelSim, QuestaSim, etc.)

### Running Simulations

```bash
# Open the Vivado project
vivado uart_protocol.xpr
```
